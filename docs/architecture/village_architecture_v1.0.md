# AI Agent Village — System Architecture (v1.0)

## Vision

**AI Agent Village** unites a warm, polymath **Canadian All-in-One Lead Agent (`Village Commander` / "Commander North")** with a coordinated village of specialist guild agents:

1. **Village Commander ("Commander North")** — Unified conversational voice & text interface, polymath knowledge engine, task orchestrator, and automation conductor.
2. **Counselor Cedar** — Empathetic active listening, CBT thought reframing, mood & energy check-ins, and guided breathing wellness sanctuary.
3. **Builder MacKenzie** — Full-stack application, tool, schema, and interactive sandbox builder.
4. **Artist Laurentian** — High-resolution visual art, photography composition, posters, and storyboards.
5. **Maestro St. Lawrence** — Multi-track DSP WAV music composition, ambient soundscapes, and voice synthesis.
6. **Director Borealis** — Motion video studio, featureette movie director, and episodic TV/web series showrunner.
7. **Scholar Champlain** — Quantitative analysis, scientific & historical research, and bilingual EN/FR mastery.
8. **Sentinel Algonquin** — Independent verification auditor certifying deliverables and `DBT-001` invariants.

## Runtime Stack

- **Database**: PostgreSQL 16 (`@electric-sql/pglite` embedded persistent store + Docker PostgreSQL 16 compatibility)
- **Backend**: Express 5 + TypeScript (`server/`) with canonical 7-stage task orchestrator, automation scheduler, DSP WAV synthesizer, procedural artwork & cinema generator, and live DBT-001 verification engine
- **Frontend**: React 19 + TypeScript + Tailwind CSS v4 + Vite 6 (`client/`) featuring Web Speech (`en-CA`) live voice dialogue, 60fps HTML5 Canvas Screening Room theater, WebM video exporter, live sandboxed app previewer, and DBT-001 database inspector
