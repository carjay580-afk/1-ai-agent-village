# DBT-001 v1.1 Patch Notes

## Summary

Upgrades the **AI Agent Village** database integrity suite (`DBT-001`) from `v1.0` to `v1.1` with authoritative persisted-state assertions, explicit agent version binding checks, full 7-stage lifecycle audit verification, and hardened transactional rollback / check-constraint verification.

## Key Hardening Changes (`v1.0` -> `v1.1`)

1. **Explicit Commander Version Binding (`agent_versions`)**
   - Verifies `agent_versions` contains canonical test version `1.0.0-dbt001` for `Village Commander`.
   - Asserts `task_agent_assignments` binds `task_id`, `agent_id`, `agent_version_id`, and `role = 'commander'`.
2. **Complete 7-Stage Lifecycle Audit Trail (`audit_events`)**
   - Replaces the `v1.0` minimum audit count check (`>= 1`) with an exact `count(DISTINCT event_type) = 7` assertion across:
     - `TASK_CREATED`
     - `TASK_PLANNED`
     - `AGENT_ASSIGNED`
     - `TASK_EXECUTION_STARTED`
     - `TASK_VERIFICATION_STARTED`
     - `TASK_VERIFIED`
     - `TASK_COMPLETED`
3. **Verification-Before-Completion Gate & Rollback Atomicity**
   - `DBT-001_transaction_rollback_v1.1.sql` verifies that attempting to persist `execution_status = 'COMPLETED'` while `verification_status = 'UNVERIFIED'` raises `check_violation`.
   - Verifies multi-table `ROLLBACK` leaves zero leaked rows across `tasks`, `task_steps`, `task_agent_assignments`, `tool_executions`, and `audit_events`.
